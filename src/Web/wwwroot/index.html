      Processing

      GET PUT /api/processing

      Pause holds commands. The handler does not run, and the command is sent back to the same endpoint in 30 seconds. Events keep processing. Pausing the enroll command delays the welcome-order command. Pausing “Write welcome order” holds the SQL write after the event has been handled. Route to error still applies to commands and events, with no retries.
